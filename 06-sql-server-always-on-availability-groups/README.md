
# SQL Server Always On Availability Groups

## Project Status

🚧 In Progress

## Project Objective

Design, configure, and document a SQL Server Always On Availability Groups environment to demonstrate enterprise-grade high availability and disaster recovery.

## Skills Demonstrated

- Windows Server Failover Clustering (WSFC)
- SQL Server Always On Availability Groups
- Availability Group configuration
- Primary and secondary replicas
- Availability Group Listener
- Synchronous and asynchronous commit
- Automatic and manual failover
- Read-only routing
- Backup preferences
- Health monitoring
- Troubleshooting

## Planned Project Deliverables

- Architecture diagram
- Configuration scripts
- Validation scripts
- Failover testing
- Troubleshooting documentation
- Screenshots
- Technical documentation

## Environment

- SQL Server Developer Edition
- Windows Server
- SQL Server Management Studio (SSMS)

## Project Workflow

1. Build the Windows Server Failover Cluster
2. Install and configure SQL Server
3. Enable Always On Availability Groups
4. Create the Availability Group
5. Configure replicas
6. Configure the listener
7. Test automatic failover
8. Test manual failover
9. Validate database synchronization
10. Document the environment
